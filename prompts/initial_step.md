Правила для правильного unified diff патча:
- Заголовок ханка `@@ -a,b +c,d @@` должен содержать точные числа: `b` — сколько строк удалено (с префиксом `-`), `d` — сколько строк добавлено (с префиксом `+`). Внимательно пересчитай строки перед тем, как написать заголовок.
- Контекстные строки (начинающиеся с пробела) должны быть точной копией соответствующих строк из текущего кода.
- Каждая удаляемая строка должна начинаться с `-`.
- Каждая добавляемая строка должна начинаться с `+`.
- Для нового файла (пустой solution.py) используй `--- /dev/null` и `+++ solution.py`. Заголовок должен быть `@@ -0,0 +1,N @@`, где N — точное количество строк в твоём патче.
- Для существующего файла используй `--- solution.py` и `+++ solution.py`.
- Не добавляй гитовские заголовки (`diff --git`, `new file mode`, `index`).
- Не оборачивай патч в markdown-блок (\`\`\`diff).
Отвечай только содержимым патча.
