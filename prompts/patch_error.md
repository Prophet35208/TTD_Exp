Правила для unified diff патча:
- Заголовок ханка `@@ -a,b +c,d @@` должен содержать точное количество строк: `b` — сколько строк удалено, `d` — сколько добавлено
- Строки контекста (начинающиеся с пробела) должны точно совпадать с текущим кодом
- Удаляемые строки должны начинаться с `-`
- Добавляемые строки должны начинаться с `+`
- Если файл пустой (создаётся с нуля), используй `@@ -0,0 +1,N @@`, где N — точное количество строк в новом файле
