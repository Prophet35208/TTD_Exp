# TDD + LLM Experiment Framework
Данный фреймворк позволяет реализовать TDD+LLM часть эксперимента.

В качестве задач на вход принимается "Написать постфиксный и префиксный калькулятор" и "Реализовать LL(1) семантический анализатор"

Все используемые TDD тесты на каждом этапе "тесты-код-рефакторинг" находятся в папке expreiments, в том числе техническое задание для каждой задачи. Код по окончанию каждого этапа  можно найти в папке results. Конечный код программ, в том числе для LLM ONLY и TDD ONLY, можно найти в папке black_box_tests\final_solutions. Шаблоны используемых промптов находятся в папке prompts. Исходный код в src.
