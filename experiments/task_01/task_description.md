Задание: 
Разработать консольное приложение calculator, которое вычисляет значение математического выражения, записанного в префиксной (польской) или постфиксной (обратной польской) нотации.
Входные параметры:
Программа читает входные данные из файла In.txt, расположенного в текущем рабочем каталоге.
Формат файла In.txt:
•	Первая строка — режим вычисления: слово prefix или postfix
•	Вторая строка — математическое выражение; все элементы выражения разделены одним или несколькими пробелами

Пример файла In.txt:
postfix
3 4 +

Вывод
Программа записывает результат в файл Out.txt, создаваемый в текущем рабочем каталоге.
Файл Out.txt должен содержать ровно одну строку.
В случае успеха программа записывает в файл результат вычисления и завершается с кодом возврата 0.
В случае ошибки программа записывает в файл строку Error и завершается с кодом возврата 1.
Файл Out.txt должен перезаписываться при каждом запуске.
Формат чисел
Операндами являются целые числа и десятичные дроби. Десятичная часть отделяется точкой. Примеры корректных операндов: 5, -3, 3.14, -0.5. Разделитель точка.
Результат выводится:
- как целое число, если результат целочисленный или, если после математического округления, до двух знаков после запятой все дробные знаки оказываются нулевыми
- как десятичная дробь ровно с двумя знаками после запятой (в том числе 7,90), если результат не является целым
Отрицательный результат предваряется знаком минус.
Операции
Программа должна поддерживать следующие операторы.
Бинарные операторы (требуют два операнда):
Оператор	Действие
+	сложение
-	вычитание
*	умножение
/	деление
%	остаток от деления
^	возведение в степень
Унарные операторы (требуют один операнд):
Оператор	Действие
sqrt	квадратный корень
abs	абсолютная величина
Ошибки
Программа обязана корректно обрабатывать ошибочные ситуации (например, деление на ноль, извлечение квадратного корня из отрицательного числа), не крашится. В ошибочной ситуации необходимо вывести Error и завершится с кодом 1. Если файл In.txt отсутствует или пуст, программа должна вывести Error и завершиться с кодом 1.
